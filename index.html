DATA & SIMULATION NOTES

Satellite positions are calculated from publicly available Two-Line Element (TLE) sets using an orbital propagation model. They are estimates, not direct live telemetry. TLE age and data availability affect accuracy. The speed slider changes the simulation clock, not the satellite's actual speed.
